# ڕێبەری کۆمپانیاکانی ئەنجوومەنی بازرگانی هەولێر

وێب‌ئەپێکی سادە کە هەموو کۆمپانیاکانی [erbilchamber.org/companies.aspx](https://www.erbilchamber.org/companies.aspx)
خۆکارانە کۆدەکاتەوە (لیست + وردەکاری هەر کۆمپانیایەک) و بە شێوەی کارتی پیشانی دەدات.

## پێکهاتە

- **`scraper.js`** — کۆدەکاتەوە. لیستی کۆمپانیاکان بە شێوەی ASP.NET AJAX partial-postback (`__VIEWSTATE` /
  `__EVENTVALIDATION` / `__EVENTTARGET` + دیلتای MS AJAX) پەیج بە پەیج دەخوێنێتەوە تا کۆتا پەیج، پاشان
  بۆ هەر کۆمپانیایەک پەڕەی `companiesDetail.aspx?id=...` دەکاتەوە بۆ وردەکاری تەواو.
- **`server.js`** — سێرڤەری Express. `/api/companies` scraper ـەکە بەکاردەهێنێت (نەک ڕاستەوخۆ browser، بۆ
  خۆپاراستن لە CORS)، ئەنجامەکە لە `companies-cache.json` هەڵدەگرێت وەک cache ـی فۆڵباک، static
  فایلەکانی frontend ـیش لەم سێرڤەرەوە serve دەکرێن.
- **`index.html` / `app.js` / `style.css`** — frontend ـی static کە داتا لە `/api/companies` وەردەگرێت.

## ڕاکردن

```bash
npm install
node server.js
```

پاشان بڕۆ بۆ http://localhost:3000

یەکەم جار کە `/api/companies` بانگ بکرێت و هیچ cache ـێک نەبێت، خۆکارانە scrape ـی تەواو ئەنجام دەدات
(نزیکەی ١ خولەک بۆ ٣٣٦ کۆمپانیا، چونکە هەر کۆمپانیایەک پەڕەی وردەکاری خۆی هەیە).

## نوێکردنەوەی داتا

- دوگمەی **↻ نوێکردنەوەی داتا** لە ئەپەکەدا scrape ـی نوێ لە سەرچاوەکە دەکات و progress بار پیشان دەدات
  (`پەیجی X` و دواتر `وردەکاری کۆمپانیا X لە Y`).
- بە شێوەی خۆکار، ئەگەر cache ـەکە تەمەنی زیاتر لە ١ کاتژمێری هەبوو، داواکارییەکی نوێ خۆکارانە scrape
  دەکاتەوە. بۆ زۆرکردنی ئەم ماوەیە، `CACHE_MAX_AGE_MS` لە `server.js` بگۆڕە.
- بۆ scrape ـی ڕاستەوخۆ لە command line:
  ```bash
  curl "http://localhost:3000/api/companies?refresh=1"
  ```
- بارستایی سکرەیپینگ لە `/api/scrape-status` بپشکنە.

## پشتڕاستکردنەوەی تەواوبوونی داتا

لە کۆتایی هەر scrape ـێک، سێرڤەر ژمارەی کۆمپانیا کۆکراوەکان لەگەڵ (ژمارەی پەیج × ٢٤) بەراورد دەکات و
duplicate ـەکان بە `id` لادەبات. لە دوا هەڵسەنگاندن: **١٤ پەیج × ٢٤ = ٣٣٦ کۆمپانیا، ٣٣٦ ID ـی یەکتا**.

چەند کۆمپانیایەک (بەپێی id) لە خودی سەرچاوەکەدا پەڕەی وردەکاریان هەڵە HTTP 500 دەدات (پشکنراوە بە
درخواستی ڕاستەوخۆ بۆ سەرچاوەکە، ئەمە کێشەی scraper ـەکە نییە)؛ بۆ ئەم حاڵەتانە تەنها ناو و چالاکی لە
پەڕەی لیستەوە وەردەگیرێت و ئەوانی تر بە `—` پیشان دەدرێن، بەپێی داواکاری "داتای خۆت دروست مەکە".

## دوگمە و کارکردنەکانی هەر کۆمپانیا

لە modal ـی وردەکاری: کردنەوەی شوێن لە Google Maps، کۆپی‌کردنی ژمارەی تەلەفۆن، کۆپی هەموو زانیاری،
کردنەوەی سەرچاوەی فەرمی لە tab ـی نوێ. هەروەها دوگمەی هەناردەی گشتی داتاکان بۆ CSV (UTF-8 + BOM) لە
سەرووی لیستەکەدا هەیە.
